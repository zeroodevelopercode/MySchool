# MySchool

A responsive school dashboard built with React and Vite.

## Features

- Flat indigo-and-white interface
- Responsive navigation and dashboard layout
- Subtle page transition animations
- Tap-highlight suppression for buttons and interactive controls
- Progressive Web App configuration
- Starter Supabase schema in `supabase/schema.sql`

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The initial preview/production deployment was created on Vercel. Connect this repository to the Vercel project to enable automatic deployments from `main`.

## Configuration

Copy `.env.example` to `.env` and configure the required environment variables before connecting backend services.
